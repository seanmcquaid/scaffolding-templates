# React Router Starters

This directory groups two React Router starters. Scaffold one of the profiles below; the profiles remain separate because they have different runtime, environment, and deployment requirements.

## SPA

Client-rendered single-page application with static output.

```bash
npx degit https://github.com/seanmcquaid/scaffolding-templates/templates/react-router/spa <project-name>
```

## SSR

Server-rendered React application with a production server entry point.

```bash
npx degit https://github.com/seanmcquaid/scaffolding-templates/templates/react-router/ssr <project-name>
```

After scaffolding either profile, follow its `README.md` and run `./scripts/setup.sh` from the generated project directory.
